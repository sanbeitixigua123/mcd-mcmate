# 演示提示词（Demo Prompts）

以下提示词可直接复制到已接入麦当劳 MCP + 本 Skill 的对话中使用。

---

## 🍔 模块 1 · 智能点餐

```
帮我点一个巨无霸套餐，到店自取。
```

```
我在上海人民广场附近，帮我看看有哪些麦当劳门店。
```

```
帮我点个板烧鸡腿堡，把中薯换成鲜蔬杯，可乐换成零度，得来速取餐。
```

```
我刚才那单到哪了？
```

---

## 💰 模块 2 · 省钱军师

```
帮我看看今天有什么券，全部领了。
```

```
用最便宜的方式帮我点一个麦辣鸡腿堡套餐，到店自取，告诉我省了多少钱。
```

```
我账户里有哪些券快过期了？优先帮我用掉。
```

```
两份巨无霸 + 两杯中可，怎么组合最省？
```

## 🥗 模块 3 · 营养配餐

```
600 大卡以内帮我配个晚餐，蛋白质高一点。
```

```
我在减脂，想吃麦当劳但不想超标，给我两个方案。
```

```
帮我配一个控钠的套餐，钠越低越好，700 大卡以内。
```

```
这个套餐和单点哪个划算？帮我算算。
```

```

```

```

```

## 🧩 组合场景

```
今晚想吃麦当劳，600 大卡以内，越便宜越好，到店自取。
```
→ 配餐（模块 3）→ 领券比价（模块 2）→ 下单（模块 1）

```
帮我看下这个月的活动，顺便用我的积分换个最划算的东西。
```
→ 活动日历（模块 4）→ 积分商城筛选（模块 4）

```
双人晚餐，预算 80 块，要有汉堡、小食和饮料，帮我配一份最省的。
```
→ 配餐（模块 3）→ 券后最优价（模块 2）→ 下单（模块 1）
